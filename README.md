
# Postcard Explorer

Visual Analytics project for exploring postcard images, metadata, topic similarity, and travel paths.

## Project structure
- `data/` metadata and small samples
- `notebooks/` experiments and analysis
- `docs/` notes and planning
- `frontend/` user interface
- `backend/` backend and API
- `assets/` mockups and figures

## Goal
Build an interactive system for:
- browsing postcards
- filtering metadata
- clustering postcard topics
- visualizing travel paths
